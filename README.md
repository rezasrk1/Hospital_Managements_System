# Hospital Management System

This is a PHP-based Hospital Management System built using HTML, CSS, JavaScript, PHP, and MySQL. It supports various administrative and patient-related functionalities and is designed for use in small to medium healthcare setups.

## 🌐 How to Run

1. Install [XAMPP](https://www.apachefriends.org/) and start Apache and MySQL.
2. Place the project in the `htdocs` folder:  
   `C:\Xampp\htdocs\hospital`
3. Open your browser and go to:  
   `http://localhost/hospital/index.php`

## 📁 Project Structure

- `admin/` – Admin dashboard and management
- `doctor/` – Doctor login and session management
- `assets/` – CSS, JS, and media assets
- `include/` – Common PHP includes like DB connection
- `master/` – Layout and template master files
- `vendor/` – Libraries (if any)
- `.sql file` – Contains database structure and sample data

## 👤 User Roles

- **Admin Login**
- **Doctor Login**
- **Patient Login**

## 🔐 Features

- Admin can manage doctors, patients, appointments, and queries
- Doctors can manage their availability and sessions
- Patients can book appointments and view history
- Forgot password and account recovery options available

## 🛠 Technologies Used

- PHP
- MySQL
- HTML5/CSS3
- JavaScript
- Bootstrap (for UI)
